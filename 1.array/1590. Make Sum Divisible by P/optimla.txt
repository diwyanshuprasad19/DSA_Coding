Yes, use this reframed version with your number example:

totalSum % p gives the extra remainder that is making the total sum not divisible by p.

Example:

nums = [8, 3, 2, 5, 7, 1, 4, 6, 2, 9]
p = 7

totalSum = 47

47 % 7 = 5

So remainder 5 is extra. That means we need to remove a subarray whose sum % 7 is also 5.

Because if we remove that extra remainder, the remaining sum will become divisible by 7.

Now the prefix part:

While moving through the array, we calculate currentMod.

currentMod means:
prefix sum till current index % p

Example at first value:

num = 8

prefixSum = 8
currentMod = 8 % 7 = 1

Now we need to remove remainder 5.

So we calculate:

targetMod = (currentMod - rem + p) % p

targetMod = (1 - 5 + 7) % 7
targetMod = 3

Meaning of 3:

3 means we need some previous prefix sum whose remainder was 3.

If previous remainder 3 exists, then the subarray between that previous index and current index will have sum % 7 = 5.

Why?

(currentMod - targetMod) % 7
= (1 - 3) % 7
= -2 % 7
= 5

So targetMod = 3 means:

Find previous prefix remainder 3.
If found, the middle subarray has removable remainder 5.

Sol:
class Solution:
    def minSubarray(self, nums: List[int], p: int) -> int:
        totalSum = sum(nums)
        rem = totalSum % p

        if rem == 0:
            return 0

        prefixMod = {0: -1}
        prefixSum = 0
        minLength = len(nums)

        for i, num in enumerate(nums):
            prefixSum += num
            currentMod = prefixSum % p
            targetMod = (currentMod - rem + p) % p

            if targetMod in prefixMod:
                minLength = min(minLength, i - prefixMod[targetMod])

            prefixMod[currentMod] = i

        return minLength if minLength < len(nums) else -1


TC:O(n)
SC:O(1)
