Mistake 1

This should start with remainder 0 frequency as 1, because empty prefix already has remainder 0.

arr = {0: 1}
Mistake 2
else:

When a new remainder comes, its frequency should become 1, not 0.

Because you have seen this remainder once now.

Correct:

else:
    arr[ind] = 1

class Solution:
    def subarraysDivByK(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count=0
        arr={0:0}
        sum=0
        for i in range(n):
            sum+=nums[i]
            ind= sum%k
            if ind==0 and ind in arr:
                count+=1
            elif ind in arr:
                arr[ind]+=1
                count+=arr[ind]
            else:
                arr[ind]=0
        
        return count
