Example
nums = [2, 1, 2, 2, 3, 2, 5, 2, 2, 7, 2]
k = 3

We need subarrays having exactly 3 odd numbers.

First convert:

Odd  -> 1
Even -> 0

So:

Original:   [2, 1, 2, 2, 3, 2, 5, 2, 2, 7, 2]
Converted:  [0, 1, 0, 0, 1, 0, 1, 0, 0, 1, 0]

Now the question becomes:

Count subarrays whose sum is exactly 3.

Because sum 3 means exactly 3 odd numbers.

Code logic
prefix_count[0] = 1
s = 0
ans = 0

for num in nums:
    s += num
    if s >= k:
        ans += prefix_count[s - k]
    prefix_count[s] += 1

Meaning:

s = odd count till current index

s - k = previous odd count needed

If previous odd count exists, then subarray between previous index and current index has exactly k odds.

Now understand why answer becomes 12

Odd numbers are at indexes:

index 1 -> 1
index 4 -> 3
index 6 -> 5
index 9 -> 7

We need exactly 3 odd numbers.

So possible groups of 3 odd numbers are:

Group 1: odd indexes 1, 4, 6
Group 2: odd indexes 4, 6, 9

Sol1:

class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        for i in range(len(nums)):
            nums[i] %= 2
        
        prefix_count = [0] * (len(nums) + 1)
        prefix_count[0] = 1
        s = 0
        ans = 0
        
        for num in nums:
            s += num
            if s >= k:
                ans += prefix_count[s - k]
            prefix_count[s] += 1
        
        return ans

2. Sliding Window Explanation

Sliding window code:

class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        return self.atMost(nums, k) - self.atMost(nums, k - 1)
    
    def atMost(self, nums: List[int], k: int) -> int:
        s, ans = 0, 0
        j = 0

        for i in range(len(nums)):
            s += nums[i] % 2

            while s > k:
                s -= nums[j] % 2
                j += 1

            ans += (i - j + 1)

        return ans

Main formula:

exactly k = atMost(k) - atMost(k - 1)

For this example:

exactly 3 odds = atMost(3 odds) - atMost(2 odds)

Why?

atMost(3) contains subarrays with 0, 1, 2, 3 odds
atMost(2) contains subarrays with 0, 1, 2 odds

Subtract them, only exactly 3 odds remain.

Final Sliding Window Answer
exactly 3 = atMost(3) - atMost(2)
exactly 3 = 62 - 50
exactly 3 = 12

Same answer as prefix sum.

Why ans += i - j + 1?

After shrinking, window [j ... i] is valid.

That means all subarrays ending at i and starting from j to i are valid.

Example from atMost(3) at index 6:

j = 0
i = 6
window = [2,1,2,2,3,2,5]

Valid subarrays ending at index 6:

6 to 6
5 to 6
4 to 6
3 to 6
2 to 6
1 to 6
0 to 6

Total:

7 = i - j + 1

So we add 7.

class Solution:
    def solv(self,nums,k):
        count=0
        ans=0
        j=0
        for i in range(len(nums)):
            count+=nums[i]%2

            while count>k:
                count-=nums[j]%2
                j+=1


            ans+=(i-j+1)
        
        return ans
        
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        return self.solv(nums,k)-self.solv(nums,k-1)
