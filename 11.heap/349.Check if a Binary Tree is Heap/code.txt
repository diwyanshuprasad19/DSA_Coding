//If All Values Are the Same in a Heap, Is It a Min Heap or Max Heap?
If all values in a heap are the same, then the heap is both a Min Heap and a Max Heap simultaneously.

Code:

✅ Python Code — Check if a Binary Tree is a Max Heap
Node Definition
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

Count Total Nodes (CBT helper)
def count_nodes(root):
    if root is None:
        return 0
    return 1 + count_nodes(root.left) + count_nodes(root.right)

Validate Heap Property + CBT
def is_heap_util(root, n, index):
    # Empty node satisfies heap
    if root is None:
        return True

    # CBT violation
    if index >= n:
        return False

    # Max-Heap property violation
    if root.left and root.data < root.left.data:
        return False
    if root.right and root.data < root.right.data:
        return False

    return (is_heap_util(root.left, n, 2 * index + 1) and
            is_heap_util(root.right, n, 2 * index + 2))

Main Function
def isHeap(root):
    if root is None:
        return True

    n = count_nodes(root)
    return is_heap_util(root, n, 0)

🧪 Sample Input & Output
Example 1: Valid Max Heap
        10
       /  \

     / \

root = Node(10)

root.right = Node(8)
root.left.left = Node(7)
