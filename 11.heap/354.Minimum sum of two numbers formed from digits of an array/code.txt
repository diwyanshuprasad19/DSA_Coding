🔹 What is ord()?

ord() returns the ASCII value of a character.

Examples:

ord('0') = 48
ord('1') = 49
ord('2') = 50
...
ord('9') = 57

def add_strings(s1, s2):
    i = len(s1) - 1
    j = len(s2) - 1
    carry = 0
    res = []

    while i >= 0 or j >= 0 or carry:
        total = carry
        if i >= 0:
            total += ord(s1[i]) - ord('0')
            i -= 1
        if j >= 0:
            total += ord(s2[j]) - ord('0')
            j -= 1

        res.append(chr(total % 10 + ord('0')))
        carry = total // 10

    return ''.join(reversed(res))


def min_sum(arr):
    # Count frequency of digits 0–9
    count = [0] * 10
    for digit in arr:
        count[digit] += 1

    s1, s2 = "", ""
    first = True

    # Distribute digits alternately in sorted order
    for digit in range(10):
        while count[digit] > 0:
            if first:
                if not (s1 == "" and digit == 0):
                    s1 += str(digit)
                first = False
            else:
                if not (s2 == "" and digit == 0):
                    s2 += str(digit)
                first = True
            count[digit] -= 1

    if s1 == "":
        s1 = "0"
    if s2 == "":
        s2 = "0"

    return add_strings(s1, s2)

🧠 Explanation (Intuition)

Count sort idea
Since digits are from 0–9, we count occurrences instead of sorting → faster.

Greedy distribution
Distribute digits alternately to two numbers starting from the smallest digit.

Avoid leading zeros
Skip 0 when the number is still empty.

Add as strings
Numbers may be very large → string addition avoids overflow.
