🟦 Python Equivalent (LeetCode / GFG Style)
import heapq

class Solution:
    def kthLargest(self, Arr, N, K):
        min_heap = []

        for i in range(N):
            curr_sum = 0
            for j in range(i, N):
                curr_sum += Arr[j]
                heapq.heappush(min_heap, curr_sum)

                if len(min_heap) > K:
                    heapq.heappop(min_heap)

        return min_heap[0]

⏱ Time Complexity

Total subarrays = N*(N+1)/2 ≈ O(N²)

Each heap operation = O(log K)

✅ Final Time Complexity
O(N² log K)

📦 Space Complexity

Heap stores at most K elements

✅ Space Complexity
O(K)
