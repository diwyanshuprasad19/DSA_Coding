🧪 Example

Input

arr = [4, 3, 2, 6]


Output

29


Explanation

Step 1: Pick 2 and 3 → cost = 5
        Heap becomes: [4, 5, 6]

Step 2: Pick 4 and 5 → cost = 9
        Total cost = 5 + 9 = 14
        Heap becomes: [6, 9]

Step 3: Pick 6 and 9 → cost = 15
        Total cost = 14 + 15 = 29

🐍 Python Implementation (Equivalent to Your C++ Code)
import heapq

def minCost(arr):
    # Create min-heap
    heapq.heapify(arr)
    
    total_cost = 0

    # Continue until one rope remains
    while len(arr) > 1:
        first = heapq.heappop(arr)
        second = heapq.heappop(arr)

        cost = first + second
        total_cost += cost

        heapq.heappush(arr, cost)

    return total_cost

▶️ Sample Run
arr = [4, 3, 2, 6]
print(minCost(arr))


Output

29

⏱ Time Complexity
Heap Operations

Heapify: O(n)

Each pop/push: O(log n)

Total operations: n − 1 merges

✅ Final Time Complexity
O(n log n)

💾 Space Complexity

Min-heap stores up to n elements

✅ Final Space Complexity
O(n)

📌 Why Greedy + Min Heap?

Always combining the two smallest ropes first ensures the minimum cost

This is the Optimal Merge Pattern, used in:

File merging

Huffman Coding

Rope connection problems
