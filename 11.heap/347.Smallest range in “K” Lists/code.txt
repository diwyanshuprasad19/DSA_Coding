Code:

import heapq
import math

def smallest_range(nums):
    # Min-heap: (value, list_index, element_index)
    min_heap = []
    cur_max = -math.inf

    # Step 1: Initialize heap with first element of each list
    for i in range(len(nums)):
        heapq.heappush(min_heap, (nums[i][0], i, 0))
        cur_max = max(cur_max, nums[i][0])

    # Smallest range [start, end]
    small_range = [0, math.inf]

    # Step 2: Process heap
    while min_heap:
        cur_min, list_idx, elem_idx = heapq.heappop(min_heap)

        # Update range if smaller
        if cur_max - cur_min < small_range[1] - small_range[0]:
            small_range = [cur_min, cur_max]

        # Move to next element in the same list
        if elem_idx + 1 < len(nums[list_idx]):
            next_val = nums[list_idx][elem_idx + 1]
            heapq.heappush(min_heap, (next_val, list_idx, elem_idx + 1))
            cur_max = max(cur_max, next_val)
        else:
            # One list exhausted → cannot cover all lists anymore
            break

    return small_range

🧪 Sample Input & Output
Example 1
nums = [
    [4, 10, 15, 24, 26],
    [0, 9, 12, 20],
    [5, 18, 22, 30]
]

print(smallest_range(nums))

✅ Output
[20, 24]

Explanation

Range [20, 24] includes:

24 from list 1

20 from list 2

22 from list 3

This is the smallest possible range covering at least one element from each list.


⏱ Time Complexity

Let:

K = number of lists

N = total number of elements across all lists

Breakdown:

Initial heap build → O(K)

Each element pushed & popped once → O(N log K)

✅ Final Time Complexity
O(N log K)

📦 Space Complexity

Heap stores at most K elements → O(K)

Constant extra variables

✅ Final Space Complexity
O(K)
