import heapq
from collections import Counter

def reorganize_string(s):
    # Step 1: Frequency map
    freq = Counter(s)

    # Step 2: Max heap using negative frequency
    max_heap = [(-count, ch) for ch, count in freq.items()]
    heapq.heapify(max_heap)

    prev_count, prev_char = 0, ''
    result = []

    # Step 3: Process heap
    while max_heap:
        count, ch = heapq.heappop(max_heap)
        result.append(ch)

        # Push back previous character if still available
        if prev_count < 0:
            heapq.heappush(max_heap, (prev_count, prev_char))

        # Decrease current character frequency
        count += 1   # because count is negative
        prev_count, prev_char = count, ch

    # Step 4: Validate
    if len(result) == len(s):
        return "".join(result)
    return ""

⏱ Time Complexity

Let:

N = length of string

K = number of unique characters (≤ 26 for lowercase letters)

Breakdown:

Frequency counting: O(N)

Heap creation: O(K log K)

Heap processing (N pops/pushes): O(N log K)

✅ Total Time Complexity
O(N log K)


Since K ≤ 26, log K is constant →

🔥 Effective Time Complexity:
O(N)

📦 Space Complexity

Frequency map → O(K)

Heap → O(K)

Result string → O(N)

Extra variables → O(1)

✅ Total Space Complexity
O(N)
