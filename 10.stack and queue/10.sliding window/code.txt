Code:

#include <iostream>
#include <vector>
#include <deque>

using namespace std;

class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        vector<int> ans;
        deque<int> dq;

        // Process the first window
        for (int i = 0; i < k; i++) {
            int element = nums[i];

            // Remove smaller elements from the back
            while (!dq.empty() && element > nums[dq.back()]) {
                dq.pop_back();
            }

            // Insert the current index
            dq.push_back(i);
        }

        // Process the remaining windows
        for (int i = k; i < nums.size(); i++) {
            // Store the maximum element of the previous window
            ans.push_back(nums[dq.front()]);

            // Remove elements that are out of the window range
            if (!dq.empty() && i - dq.front() >= k) {
                dq.pop_front();
            }

            // Remove smaller elements from the back
            int element = nums[i];
            while (!dq.empty() && element > nums[dq.back()]) {
                dq.pop_back();
            }

            // Insert the current index
            dq.push_back(i);
        }

        // Push the maximum of the last window
        ans.push_back(nums[dq.front()]);

        return ans;
    }
};

// Driver Code
int main() {
    Solution sol;
    vector<int> nums = {1, 3, -1, -3, 5, 3, 6, 7};
    int k = 3;
    
    vector<int> result = sol.maxSlidingWindow(nums, k);

    // Print the result
    cout << "Max elements in each sliding window: ";
    for (int num : result) {
        cout << num << " ";
    }
    cout << endl;

    return 0;
}


time and space:

Time and Space Complexity Analysis of Sliding Window Maximum Algorithm
Time Complexity Analysis
The algorithm uses a deque (double-ended queue) to efficiently track the maximum elements in each sliding window.

Processing Each Element Once (O(N))

Each element is pushed into the deque once.
Each element is removed from the deque once.
Hence, each element is processed at most twice (once for insertion, once for removal).
Operations Inside the Loop (O(1))

Insertion (push_back()): Each index is added at most once.
Removal (pop_front() and pop_back()): Elements are removed at most once.
Accessing the Maximum (dq.front()): This takes constant time O(1).

Space Complexity Analysis
The space complexity is determined by:

Result Array (ans):

Stores the maximum of each window.
Contains approximately (N - k + 1) elements.
Space complexity: O(N) in the worst case.
Deque (dq):

Stores at most k elements (indices of array elements).
At any point, the deque size is at most k, leading to O(k) space complexity.
