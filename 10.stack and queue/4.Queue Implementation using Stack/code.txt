✅ Queue Using Single Stack (Python)
class QueueUsingOneStack:
    def __init__(self):
        self.s = []

    def push(self, x):
        # Simply push
        self.s.append(x)

    def pop(self):
        if not self.s:
            print("Queue Underflow")
            return -1

        # Remove top
        top_element = self.s.pop()

        # If stack becomes empty → this was the front
        if not self.s:
            return top_element

        # Recursive call
        front_element = self.pop()

        # Push back other elements
        self.s.append(top_element)

        return front_element

    def front(self):
        if not self.s:
            print("Queue is empty")
            return -1

        top_element = self.s.pop()

        if not self.s:
            # This is front
            self.s.append(top_element)
            return top_element

        front_element = self.front()

        self.s.append(top_element)

        return front_element

    def size(self):
        return len(self.s)
📥 Sample Input
q = QueueUsingOneStack()
q.push(1)
q.push(2)
q.push(3)

print("Front:", q.front())
print("Popped:", q.pop())
print("Size:", q.size())
📤 Sample Output
Front: 1
Popped: 1
Size: 2
🧠 How It Works (Important)

Suppose stack looks like:

Top
3
2
1   ← bottom (actual queue front)

When calling pop():

Remove 3

Remove 2

Remove 1 (this is front)

Rebuild stack → push back 2, 3

Final stack:

Top
3
2

Queue behavior achieved ✅

⏱ Time Complexity
Operation	Complexity
push()	O(1)
pop()	O(N)
front()	O(N)
size()	O(1)
📦 Space Complexity

O(N)

Because:

Stack stores N elements

Recursion call stack also goes up to N
