✅ Python Stack Implementation
class Stack:
    def __init__(self, size=1000):
        self.size = size
        self.arr = [0] * size
        self.top = -1

    def push(self, x):
        if self.top >= self.size - 1:
            print("Stack Overflow")
            return
        self.top += 1
        self.arr[self.top] = x

    def pop(self):
        if self.top == -1:
            print("Stack Underflow")
            return -1
        value = self.arr[self.top]
        self.top -= 1
        return value

    def Top(self):
        if self.top == -1:
            print("Stack is empty")
            return -1
        return self.arr[self.top]

    def Size(self):
        return self.top + 1


# Function Calls
s = Stack()
s.push(6)
s.push(7)
s.push(8)

print("Popped:", s.pop())
print("Top:", s.Top())
print("Size:", s.Size())
📥 Sample Input (Operations Performed)
push(6)
push(7)
push(8)
pop()
Top()
Size()
📤 Sample Output
Popped: 8
Top: 7
Size: 2
⏱ Time Complexity
Operation	Complexity
push()	O(1)
pop()	O(1)
Top()	O(1)
Size()	O(1)

👉 All operations are constant time because:

We directly access index using top

No loops involved

📦 Space Complexity
O(N)

Where:

N = maximum size of stack

We allocate an array of size N
