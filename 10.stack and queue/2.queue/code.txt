✅ Circular Queue (Optimal Implementation)
class CircularQueue:
    def __init__(self, capacity):
        self.capacity = capacity
        self.arr = [0] * capacity
        self.front = 0
        self.size = 0
        self.rear = -1

    def push(self, x):
        if self.size == self.capacity:
            print("Queue is full")
            return
        
        # Circular increment
        self.rear = (self.rear + 1) % self.capacity
        self.arr[self.rear] = x
        self.size += 1

    def pop(self):
        if self.size == 0:
            print("Queue is empty")
            return -1
        
        value = self.arr[self.front]
        
        # Circular increment
        self.front = (self.front + 1) % self.capacity
        self.size -= 1
        
        return value

    def Front(self):
        if self.size == 0:
            print("Queue is empty")
            return -1
        return self.arr[self.front]

    def Size(self):
        return self.size

🧠 How Circular Works

Instead of shifting elements:

rear = (rear + 1) % capacity
front = (front + 1) % capacity

When index reaches end → it wraps to 0.

Example:

capacity = 5

Index: 0 1 2 3 4
After reaching 4,
Next index = (4 + 1) % 5 = 0

So we reuse empty spaces.
