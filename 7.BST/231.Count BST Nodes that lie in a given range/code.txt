Code:

#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node* left, *right;

    Node(int val) {
        data = val;
        left = right = NULL;
    }
};

int getCount(Node *root, int l, int h) {
    if (root == NULL) return 0;

    // If root's data is within the range
    if (root->data >= l && root->data <= h)
        return 1 + getCount(root->left, l, h) + getCount(root->right, l, h);
    
    // If root's data is smaller than 'l', move to the right subtree
    if (root->data < l)
        return getCount(root->right, l, h);
    
    // If root's data is greater than 'h', move to the left subtree
    return getCount(root->left, l, h);
}


Time and space compelxity:
Time and Space Complexity Analysis:
Time Complexity:
Best & Average Case (Balanced BST):
The function skips unnecessary branches when root->data is outside [l, h], making the time complexity O(log N).
Worst Case (Skewed BST or when all nodes are within range):
The function visits all N nodes, resulting in O(N) complexity.
Thus, overall time complexity:

O(log N) (Balanced BST)
O(N) (Skewed BST / Unrestricted range case)
Space Complexity:
Since the function uses recursion, the worst-case space complexity is determined by the recursion stack depth:
O(log N) for a balanced BST (height of tree).
O(N) for a skewed BST (worst case).
Thus, space complexity:

O(log N) (Balanced BST)
O(N) (Skewed BST, recursive calls stack overhead)
