Code:

Python Version (Pure Recursion – Same Logic)
def solve(i, j):
    if i == 0 and j == 0:
        return 1
    if i < 0 or j < 0:
        return 0

    up = solve(i - 1, j)
    left = solve(i, j - 1)
    return up + left


def unique_paths(m, n):
    return solve(m - 1, n - 1)


if __name__ == "__main__":
    m, n = 3, 7
    result = unique_paths(m, n)
    print("Unique Paths:", result)

🧪 Sample Input
m = 3
n = 7

✅ Sample Output
Unique Paths: 28

🧠 Key Idea (Same as C++)

We start from (m-1, n-1) and try to reach (0, 0)

From any cell (i, j) we can:

Move up → (i-1, j)

Move left → (i, j-1)

Total paths = paths from up + left

solve(i, j) = solve(i-1, j) + solve(i, j-1)

⏱️ Time Complexity
O(2^(m + n))

Why?

Each call branches into two recursive calls

Maximum recursion depth ≈ m + n

Similar to naive Fibonacci recursion

No memoization, so many overlapping subproblems are recomputed

🗂️ Space Complexity
O(m + n)

Why?

Due to recursion call stack

Maximum depth = total moves = m + n
