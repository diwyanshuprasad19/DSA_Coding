Code:

#include <bits/stdc++.h>
using namespace std;

int solve(int i, int j, vector<vector<int>>& triangle, int n) {
    if (i == n - 1)
        return triangle[i][j];

    int down = triangle[i][j] + solve(i + 1, j, triangle, n);
    int diagonal = triangle[i][j] + solve(i + 1, j + 1, triangle, n);
    return min(down, diagonal);
}

int minimumPathSum(vector<vector<int>>& triangle, int n) {
    return solve(0, 0, triangle, n);
}

int main() {
    vector<vector<int>> triangle = {
        {2},
        {3, 4},
        {6, 5, 7},
        {4, 1, 8, 3}
    };
    int n = triangle.size();
    cout << minimumPathSum(triangle, n) << endl;
    return 0;
}


Input and output:

Input:
triangle = {
  {2},
  {3, 4},
  {6, 5, 7},
  {4, 1, 8, 3}
}
n = 4

Output:
11


 3. Time and Space Complexity (Recursive Only)
⏱ Time Complexity: O(2^n)
At each cell, you make 2 choices: move down or diagonal.

In worst case, total recursive calls = 2^(n-1) + 2^(n-2) + ... + 1 = O(2^n)

This is exponential and not suitable for large n.

💾 Space Complexity: O(n)
Recursion stack depth = n (because you go from top to bottom in the triangle)

No extra space used apart from the recursion stack (since there’s no memoization)
