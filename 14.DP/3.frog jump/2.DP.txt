✅ Updated Version: Top-Down DP (Memoized)
def minCostClimbingStairs(cost):
    n = len(cost)
    dp = [-1] * n   # memo array

    def solve(i):
        if i < 0:
            return 0
        if i == 0 or i == 1:
            return cost[i]

        if dp[i] != -1:      # already computed
            return dp[i]

        dp[i] = cost[i] + min(
            solve(i - 1),
            solve(i - 2)
        )
        return dp[i]

    return min(solve(n - 1), solve(n - 2))

🧪 Sample Input 1
cost = [10, 15, 20]
print(minCostClimbingStairs(cost))

✅ Output
15

Explanation

Start at index 1

Pay 15

Jump two steps → reach top

🧪 Sample Input 2
cost = [1,100,1,1,1,100,1,1,100,1]
print(minCostClimbingStairs(cost))

✅ Output
6

Explanation (path)
0 → 2 → 4 → 6 → 7 → 9 → top
Costs paid: 1 + 1 + 1 + 1 + 1 + 1 = 6

⏱️ Time & Space Complexity
Metric	Value
Time Complexity	O(n)
Space Complexity	O(n)
Reason	Each index computed once + recursion stack
