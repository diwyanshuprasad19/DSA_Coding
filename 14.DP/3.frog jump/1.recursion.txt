def minCostClimbingStairs(cost):
    n = len(cost)

    def solve(i):
        if i < 0:
            return 0
        if i == 0 or i == 1:
            return cost[i]

        return cost[i] + min(
            solve(i - 1),
            solve(i - 2)
        )

    return min(solve(n - 1), solve(n - 2))

Sample Input 1
cost = [10, 15, 20]
print(minCostClimbingStairs(cost))

✅ Output
15
Explanation
Start at index 1

Pay 15

Jump two steps → reach top

🧪 Sample Input 2
cost = [1,100,1,1,1,100,1,1,100,1]
print(minCostClimbingStairs(cost))
✅ Output
6
Explanation (path)
0 → 2 → 4 → 6 → 7 → 9 → top
Costs paid: 1 + 1 + 1 + 1 + 1 + 1 = 6

Metric	Value
