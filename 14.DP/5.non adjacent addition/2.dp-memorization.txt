def solve(index, nums, dp):
    if index == 0:
        return nums[index]
    if index < 0:
        return 0
    if dp[index] != -1:
        return dp[index]

    pick = nums[index] + solve(index - 2, nums, dp)
    not_pick = solve(index - 1, nums, dp)

    dp[index] = max(pick, not_pick)
    return dp[index]


def maximum_non_adjacent_sum(nums):
    k = len(nums)
    dp = [-1] * k
    return solve(k - 1, nums, dp)

v = [1, 2, 3, 4]
result = maximum_non_adjacent_sum(v)
print(result)

🧪 Sample Input
v = [1, 2, 3, 4]

✅ Sample Output
6

🧠 Explanation

At each index:

pick → take current element + solve(index-2)

not pick → skip current element + solve(index-1)

Memoization ensures each index is computed once.

Optimal choice:

2 + 4 = 6

⏱️ Time & Space Complexity
Metric	Value
Time Complexity	O(n)
Space Complexity	O(n)
Details	dp[n] for memoization + recursion stack
