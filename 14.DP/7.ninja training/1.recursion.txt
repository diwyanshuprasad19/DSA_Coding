sys.maxsize

A very large number

Still finite

Example
import sys

x = sys.maxsize
print(x)          # very big number
print(x + 1)      # still increases


Meaning:
➡️ “Big, but not infinite”

float('inf')

Represents infinity

Has no limit

Example
x = float('inf')
print(x)
print(x + 100)    # still infinity


Meaning:
➡️ “No end, no maximum”

Simple Difference
print(sys.maxsize > 10**100)     # False
print(float('inf') > 10**100)    # True

When to use

Use sys.maxsize → for sizes or indexing

Use infinity → for algorithm comparisons (DP, graphs)

✅ Python Code
import sys
sys.setrecursionlimit(10**7)

def solve(index, last, points):
    if index == 0:
        maxi = -10**9
        for i in range(3):
            if i != last:
                maxi = max(maxi, points[0][i])
        return maxi

    maxi = -10**9
    for i in range(3):
        if i != last:
            p = points[index][i] + solve(index - 1, i, points)
            maxi = max(maxi, p)

    return maxi


def ninjaTraining(n, points):
    return solve(n - 1, 3, points)


if __name__ == "__main__":
    points = [
        [10, 50, 1],
        [5, 100, 11],
        [20, 5, 90]
    ]

    n = len(points)
    result = ninjaTraining(n, points)
    print("Maximum Points:", result)

⏱️ Time Complexity
O(3^n)


Reason
At each day (n levels), the function tries up to 3 activities (excluding the last one), leading to exponential branching.

🗂️ Space Complexity
O(n)


Reason
Only the recursion stack is used, with maximum depth equal to the number of days n.
