COde:

#include <bits/stdc++.h>
using namespace std;

int countSubsequences(int i, int j, string &s, string &t) {
    // If target exhausted, 1 valid subsequence found
    if (j < 0) return 1;

    // If source exhausted but target still remains
    if (i < 0) return 0;

    // If characters match: we have 2 choices
    if (s[i] == t[j]) {
        return countSubsequences(i - 1, j - 1, s, t) + countSubsequences(i - 1, j, s, t);
    } else {
        // If characters don't match: skip current character of s
        return countSubsequences(i - 1, j, s, t);
    }
}

int numDistinct(string s, string t) {
    int n = s.size();
    int m = t.size();
    return countSubsequences(n - 1, m - 1, s, t);
}

Explanation:
The string "bag" can be formed in 5 different ways from "babgbag" as subsequences:

b a g

b a g (second g)

b a g (third g)

b g g

b g a g

⏱ Time & Space Complexity
Metric	Value
Time	O(2^n) (Exponential in n)
Space (stack)	O(n + m) (recursive depth)

Where n = s.length(), m = t.length()
