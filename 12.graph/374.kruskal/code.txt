Python – Disjoint Set (Union by Rank)
class DisjointSet:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, node):
        # Path compression
        if node != self.parent[node]:
            self.parent[node] = self.find(self.parent[node])
        return self.parent[node]

    def union_by_rank(self, u, v):
        pu = self.find(u)
        pv = self.find(v)

        if pu == pv:
            return False

        if self.rank[pu] < self.rank[pv]:
            self.parent[pu] = pv
        elif self.rank[pv] < self.rank[pu]:
            self.parent[pv] = pu
        else:
            self.parent[pv] = pu
            self.rank[pu] += 1

        return True

✅ Kruskal’s Algorithm (MST)
def spanning_tree(V, adj):
    edges = []

    # Step 1: Extract edges from adjacency list
    for u in range(V):
        for v, wt in adj[u]:
            edges.append((wt, u, v))

    # Step 2: Sort edges by weight
    edges.sort()

    ds = DisjointSet(V)
    mst_weight = 0

    # Step 3: Pick edges greedily
    for wt, u, v in edges:
        if ds.union_by_rank(u, v):
            mst_weight += wt

    return mst_weight

⏱️ Time Complexity (Union by Rank)
O(N + E) + O(E log E) + O(E × α(N))

Breakdown:

O(N + E) → Extract edges

O(E log E) → Sort edges

O(E × α(N)) →

find() + union_by_rank()

α(N) ≤ 4 (inverse Ackermann, constant)

👉 Overall: O(E log E)

💾 Space Complexity
O(N) + O(E)

edges[] → O(E)

parent[] → O(N)

rank[] → O(N)
