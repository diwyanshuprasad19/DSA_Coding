✅ Python Implementation – DFS Topological Sort
def topo_sort_dfs(V, adj):
    visited = [False] * V
    stack = []

    def dfs(node):
        visited[node] = True
        for neighbor in adj[node]:
            if not visited[neighbor]:
                dfs(neighbor)
        # Push to stack AFTER visiting all neighbors
        stack.append(node)

    # Call DFS for all unvisited nodes
    for i in range(V):
        if not visited[i]:
            dfs(i)

    # Reverse stack to get topological order
    return stack[::-1]

🧪 Sample Driver Code
V = 6
adj = [
    [],        # 0
    [],        # 1
    [3],       # 2 → 3
    [1],       # 3 → 1
    [0, 1],    # 4 → 0, 1
    [0, 2]     # 5 → 0, 2
]

result = topo_sort_dfs(V, adj)
print(result)

🧠 How DFS Topological Sort Works (Simple)
Core Idea:

A node is added to the stack after all its dependencies are processed.

Steps:

Maintain a visited[] array

Run DFS on every unvisited node

After DFS finishes for a node → push it to stack

Reverse the stack to get topological order

⏱️ Time Complexity
O(V + E)

Each vertex visited once → O(V)

Each edge explored once → O(E)

💾 Space Complexity
O(V + E)

Visited array → O(V)

Recursion stack → O(V)

Adjacency list → O(E)
