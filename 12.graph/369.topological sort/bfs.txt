Kahn sorting

Video:https://www.youtube.com/watch?v=73sneFXuTEg

Topological sorting only works for Directed Acyclic Graphs (DAGs) and does not apply to undirected graphs.

Sol:https://takeuforward.org/data-structure/kahns-algorithm-topological-sort-algorithm-bfs-g-22/

code:

from collections import deque

def topo_sort(V, adj):
    """
    Returns a list of vertices in Topological Order
    using Kahn's Algorithm (BFS).
    """

    # Step 1: Compute indegree of each vertex
    indegree = [0] * V
    for u in range(V):
        for v in adj[u]:
            indegree[v] += 1

    # Step 2: Push all vertices with indegree 0 into queue
    q = deque()
    for i in range(V):
        if indegree[i] == 0:
            q.append(i)

    topo = []

    # Step 3: BFS
    while q:
        node = q.popleft()
        topo.append(node)

        # Reduce indegree of neighbors
        for neighbor in adj[node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                q.append(neighbor)

    return topo

🧪 Sample Driver Code
V = 6
adj = [
    [],        # 0
    [],        # 1
    [3],       # 2 → 3
    [1],       # 3 → 1
    [0, 1],    # 4 → 0, 1
    [0, 2]     # 5 → 0, 2
]

result = topo_sort(V, adj)
print(result)

📥 Sample Input (Graph)
Edges:
2 → 3
3 → 1
4 → 0
4 → 1
5 → 0
5 → 2

📤 Sample Output
[4, 5, 0, 2, 3, 1]


⚠️ Note:
Topological order may vary, but all valid outputs respect edge directions.

⏱️ Time Complexity
O(V + E)

Each vertex processed once → O(V)

Each edge processed once → O(E)

💾 Space Complexity
O(V + E)

Adjacency list → O(E)

Indegree array → O(V)

Queue + result list → O(V)
