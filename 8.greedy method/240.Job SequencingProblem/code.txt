 Code:

#include <bits/stdc++.h>
using namespace std;

struct Job {
    int id, dead, profit;
};

class Solution {
public:
    static bool comp(Job a, Job b) {
        return a.profit > b.profit; // Sort jobs by profit in descending order
    }

    vector<int> JobScheduling(Job arr[], int n) {
        // Step 1: Sort jobs based on profit
        sort(arr, arr + n, comp);

        vector<bool> v(n, false); // Tracks if a slot is occupied
        int day = 0, profit = 0;

        // Step 2: Assign jobs to the latest available slot before the deadline
        for (int i = 0; i < n; i++) {
            for (int j = min(n, arr[i].dead) - 1; j >= 0; j--) {
                if (!v[j]) { // If slot is free
                    day++;
                    profit += arr[i].profit;
                    v[j] = true;
                    break;
                }
            }
        }
        return {day, profit};
    }
};

// Driver Code
int main() {
    Solution obj;
    Job arr[] = {{1, 2, 100}, {2, 1, 19}, {3, 2, 27}, {4, 1, 25}, {5, 3, 15}};
    int n = 5;

    vector<int> result = obj.JobScheduling(arr, n);
    cout << "Max Jobs Done: " << result[0] << ", Max Profit: " << result[1] << endl;
    
    return 0;
}
Time Complexity: Sorting O(n log n) + nested slot search O(n²) ⇒ O(n²) overall.
Space Complexity: Boolean array v of size n ⇒ O(n) (sort is in-place, other vars O(1)).



Code Explanation (Step-by-Step)
We have two arrays:

deadline[i] → last time slot in which the job can be done

profit[i] → profit if we complete this job

Goal:
✅ Maximize total profit
✅ Find how many jobs are done

3. Use a Min-Heap (priority_queue with greater<int>)

priority_queue<int, vector<int>, greater<int>> pq;
This heap stores profits of currently scheduled jobs.

The smallest profit job is always at the top (so we can remove it if a better profit job comes).

4. Iterate over jobs
For each job (deadline, profit):

Case 1:
If the current job can be scheduled within its deadline:

if (job.first > pq.size())
    pq.push(job.second);
We push its profit into pq.

Case 2:
If the schedule is already full (heap size == deadline),
replace the lowest profit job if the current one is better:

Copy

else if (!pq.empty() && pq.top() < job.second) {
    pq.pop();          // remove lowest profit job
    pq.push(job.second);
}
5. Compute results
At the end:

    ans[1] += pq.top(); // total profit
    pq.pop();
    ans[0]++;           // total jobs
}
ans[0] → total jobs done
ans[1] → total profit

(1,15) → heap full, 15 < 25 → skip

(2,100) → heap size=1 < deadline=2 → heap = [25,100]

Time Complexity
Pairing jobs: O(n)

Sorting: O(n log n)

Heap operations: each job push/pop takes O(log k), where k ≤ n
⇒ O(n log n) in worst case

Total: O(n log n)

Space Complexity
Jobs array: O(n)

Min-heap: O(n) in worst case

Total: O(n)
